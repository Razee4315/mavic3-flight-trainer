Frequently asked questions

Short answers about the trainer.

Is the Mavic 3 Flight Trainer free?

Yes. It is free and open source. It runs in your browser with nothing to install.

Do I need a controller?

No. A keyboard works. Xbox and PlayStation gamepads work too, and so does an RC transmitter in USB joystick mode. Phones and tablets get on-screen sticks.

Which stick mode should I pick?

Mode 2. It is the DJI default: the left stick controls throttle and yaw, the right stick controls pitch and roll. Pick Mode 1 or 3 only if your real remote is set that way.

How realistic is it?

It uses the Mavic 3 published speeds for Cine, Normal and Sport mode, and copies GPS braking, ATTI drift, obstacle sensing and Return to Home. It is a training aid, not an exact flight model.

Can it replace real flight training?

No. Use it to learn the controls and build habits, then practise with the real aircraft in an open area and follow your local aviation rules.

Does it work on a phone?

Yes. It runs in any modern browser, including mobile Chrome and Safari, with touch sticks on screen.

Is this an official DJI product?

No. It is an unofficial Final Year Project and is not affiliated with or endorsed by DJI.
