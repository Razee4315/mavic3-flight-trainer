About the project

Why we built a Mavic 3 simulator.

A Final Year Project

This trainer is our Final Year Project. Our project needed us to learn the basic controls of a drone, and practising on a real aircraft is expensive and risky for a beginner. So we built a safe place to learn the Mavic 3 and its RC-N1 remote first.

How it's built

It's a single web page using Three.js for the 3D world, the drone and the remote. Flight behaviour follows the Mavic 3's published specs. The source is on GitHub.

Unofficial training tool. Not affiliated with or endorsed by DJI. For real flights, follow the official manual and your local aviation rules.
